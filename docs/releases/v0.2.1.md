## 更新内容

- 减少计时常驻开销：展开时每秒刷新，收起后按分钟刷新，待机和暂停每分钟检查日期。
- 到时提醒继续按实际结束时间触发；电脑休眠唤醒时立即校准。
- 提示音按需创建，关闭提醒时释放音频上下文，普通操作不再启动音频引擎。
- 历史日历按需读取，倒计时更新不再反复传输全部打卡历史。
- 移除状态灯的持续动画，启用后台节流。
- 包含此前的启动日期刷新和 MIT License。
- 28 项单元测试通过，实际窗口测试已验证收起到时提醒、音频释放和打卡日历。

本次内存对照测试在 macOS 上完成；Windows 的具体降幅需在同一电脑升级后比较，暂不承诺固定内存数值。

## 下载

- macOS Apple Silicon：DMG 或 macOS ZIP。
- Windows x64：portable ZIP，退出旧版后解压运行 `Pomodock.exe`。
- `SHA256SUMS-v0.2.1.txt` 提供文件校验值。

升级后保留计时设置与打卡记录。安装包未配置商业代码签名；Windows 包已核对内容，本次未在 Windows 真机运行。
