# Pomodock Lite v0.3.0-beta.2

修复双屏情况下，展开窗口移动到另一屏幕后，点击收起标签跳回旧屏幕的问题。此版仍为轻量预览版，不替换 Electron v0.2.2 稳定版。

## 修复

- 收起、展开、调整大小时，优先使用窗口当前所在屏幕，不再被过期的屏幕记忆覆盖。
- 收起前同步保存当前屏幕及窗口对应的标签高度；启动时仍恢复上次记住的屏幕。
- 保持顶部/底部标签锚点，避免反复展开、收起后位置逐渐漂移。
- 数据目录、设置与打卡记录格式保持不变。请先退出旧 Lite，再安装或运行新版，无需卸载或删除数据。

## 下载

- Windows x64 推荐 `Pomodock-Lite-0.3.0-beta.2-win-x64-setup.exe`；也提供裸 EXE。
- macOS Apple Silicon 下载 `mac-arm64.dmg` 或 `mac-arm64.zip`。
- 附 SHA-256 校验文件、MIT LICENSE 及第三方许可声明；裸 EXE 请同时保留这些声明。

Windows 依赖系统共享的 WebView2，缺少时安装程序联网下载运行库；裸 EXE 需提前安装运行库。50 MB 目标不含共享运行库，也不是运行内存保证。发布包未配置商业代码签名或 macOS 公证，首次打开可能出现系统安全提示。

## 验证

本地 40 项 JavaScript 测试、15 项 Rust 测试及 Electron 实际窗口冒烟测试通过。macOS 双屏原生 WebView 冒烟测试通过，使用两块真实显示器，保留旧屏幕记忆并把窗口移至另一屏，再点击界面收起按钮，验证标签仍位于新屏幕右侧；反复展开/收起、原生窗口尺寸、计时到期自动展开和历史日历亦通过。

不同缩放比例、负坐标与上下排列的定位规则有单元测试覆盖；Windows 双屏真机交互及内存尚未实测。
