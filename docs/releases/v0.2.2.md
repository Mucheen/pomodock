## 窗口交互

- 收起标签从 60×148 缩小为 36×76，面积减少约 69%。
- 按住标签可沿屏幕右侧上下拖动；拖动后松开保持收起，单击展开。
- 记住标签所在屏幕和高度，展开、再次收起或重启后保留；显示器移除后回到可用屏幕。
- 展开窗口可拖动任意边缘或四角调整大小，最小 320×500，尺寸在重启后保留。
- 小窗口下计时界面适配高度，设置和历史打卡可滚动查看。

## 包体精简

- 中英语言资源按需打包，移除其他语言包。
- React/React DOM/Scheduler 已打入前端静态资源，不再重复打包依赖目录，保留第三方许可声明。
- Windows 增加 LZMA 压缩的免安装 EXE，直接运行；同时保留便携 ZIP。
- macOS DMG 使用 LZFSE 压缩。

与 v0.2.1 对比（MiB）：

| --- | ---: | ---: |

Windows 解压后的目录从约 376 MiB 降至 327 MiB。EXE 是压缩的便携封装，运行时仍需解压 Electron；下载大小与运行时磁盘占用不同。

## 下载与验证

- Windows x64：推荐 `Pomodock-0.2.2-win-x64-portable.exe`，也可用 portable ZIP。
- macOS Apple Silicon：DMG 或 macOS ZIP。
- 退出旧版再运行新版，原有设置与打卡记录继续保留。
- 提供 SHA-256 校验文件。安装包未配置商业代码签名。
