# Pomodock Lite v0.3.0-beta.1

面向小于 50 MB 包体目标的独立轻量预览版。改用 Tauri/Rust + 系统 WebView，复用现有界面，不再随应用打包 Electron 的 Chromium/Node.js。v0.2.2 仍为最新稳定版。

## 下载

- Windows x64：推荐 `Pomodock-Lite-0.3.0-beta.1-win-x64-setup.exe`。也提供不需安装的 `win-x64.exe`。
- macOS Apple Silicon：选择 `mac-arm64.dmg` 或 `mac-arm64.zip`。
- 提供 SHA-256 校验文件、MIT LICENSE 与第三方许可声明。

Windows 复用 Microsoft Edge WebView2。系统缺少时，安装程序会联网下载共享运行库；裸 EXE 不包含运行库，需提前安装 WebView2。共享运行库的磁盘占用不计入应用体积。此处的 50 MB 是包体指标，**不是运行内存低于 50 MB 的保证**。

## 功能与数据

- 25/5/25 四轮循环、跨天按本地日期刷新今日统计、历史打卡日历。
- 36×76 屏幕右侧标签、上下拖动位置记忆、展开后边缘/四角调整尺寸与尺寸记忆。
- Rust 原生后台计时，按实际期限校准休眠/重启；到时自动展开与系统通知。
- 首次启动把旧版设置与记录复制到独立 Lite 数据目录，并保存导入备份，不修改旧版文件。请先退出旧版；迁移后两个版本的记录分别累计。

## 验证与预览限制

35 项 JavaScript 测试、9 项 Rust 测试通过；Windows 原生 CI 构建和小于 50,000,000 字节的 EXE 体积门禁通过。macOS 系统 WebView 冒烟测试覆盖真实收起按钮、原生窗口尺寸、尺寸恢复、后台到时展开及日历。

尚未完成 Windows 真机交互、混合 DPI 多屏及内存实测。该版本标记为预览版，不替换稳定版。未配置商业代码签名或 macOS 公证，首次打开可能出现系统安全提示；开源许可证不是操作系统安全认证。
