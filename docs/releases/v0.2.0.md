## 更新内容

- 新增每日专注统计：今日次数按本地日期自动刷新，跨天不会中断计时。
- 新增历史打卡日历：点击「打卡记录」查看每天的专注次数、分钟数，以及每月打卡天数。
- 默认循环改为：每轮专注 25 分钟，前 3 轮后短休息 5 分钟，第 4 轮后长休息 25 分钟，再开始下一组。
- 圆点明确标注「本组」轮次，长休息完成或跳过后归零，与今日统计和历史累计分开。
- 第 4 轮完成后提醒「开始长休息」，长休息结束后提醒「开始下一组」。到时仍需点击按钮开始下一阶段。
- 添加 22 项自动测试，覆盖完整循环、跨天刷新、休眠补记、数据迁移和日历。

## 升级说明

- 保留已有计时设置与打卡记录；如果旧版长休息仍为 15 分钟，请在设置中改为 25 分钟并保存。
- 首次使用新版循环从本组 0 轮开始，旧累计次数不会提前触发长休息。
- 旧版没有保存完成日期，原累计次数会单独保留为「升级前记录」，不计入今日，也无法还原每日分布。首次统计迁移会备份原状态文件。
- 保存设置会从第 1 轮专注开启新循环，不清空打卡历史。

## 下载

- macOS Apple Silicon：下载 DMG，打开后把 Pomodock 拖入「应用程序」；也可下载 macOS ZIP。
- Windows x64：下载 portable ZIP，解压后运行 `Pomodock.exe`。
- `SHA256SUMS-v0.2.0.txt` 提供下载文件校验值。

安装包未配置商业代码签名，首次运行可能出现开发者或 SmartScreen 提示。macOS Intel 暂未提供预编译包；Windows 包已验证内容，但未在 Windows 真机上运行测试。
